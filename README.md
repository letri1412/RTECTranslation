# RTECTranslation
_自用，RT社视频翻译流程参考_

**本页面将展示为“[RELECTECH电子音乐社区](https://space.bilibili.com/332843957)”翻译视频的流程。**
## 一、文件准备
**点击[此处](文件准备.md)跳转到对应的页面。**
## 二、编辑

前面要加片头，社区片头文件放[这里](https://github.com/letri1412/RTEDMIntros)了，视情况降低片头音量

然后是视频开头的文本（宋体，左上角，左对齐，小字，斜体，黄色）：

```
RELECTECH电子音乐社区翻译组

翻译:

审校：博洛Tonistan

原作者：

```

“翻译：”后面填上你自己的网名，“原作者：”后面填视频平台，加“@”符号，加作者的名字

示例：

```
RELECTECH电子音乐社区翻译组

翻译@letri1412

审校：博洛Tonistan

原作者：YouTube@letri1412

```

社区片头和翻译的视频之间最好加个转场（Adobe Premiere快捷键shift+d）

在视频中遇到了不符合法律法规的内容要去掉，广告和推广内容在删除后保证视频流畅

## 三、字幕
**点击[此处](字幕与翻译规范.md)跳转到对应的页面。**

## 四、审校

可选步骤，既要检查字幕是否合适，又要检查字幕时间轴是否与音频对其，及时查漏补缺。

## 五、交付
**点击[此处](交付.md)跳转到对应的页面。**

视频画幅帧率与翻译的视频相同即可，容器必须是mp4、mkv，目标比特率为2Mbps，大幅度闪动变换的可以适当调高，或者调成可变比特率

如果有能力把音频做成杜比™全景声混音，那肯定再好不过了，交付时，务必告知要勾选杜比全景声（/杜比音效）

# 第二种工作流（尚在实验）
先准备中文字幕，再用`Aegisub`建立字幕时间轴，俗称“打轴”，再把`*.ass`字幕转换成`*.srt`字幕，弄进视频编辑软件合成到视频导出即可。
