# RTECTranslation
_自用，RT社视频翻译流程参考_

**一、首先要挂上代理或VPN，不推荐Cloudflare美国相关节点**

**二、下载**

视频下载（留意了一下，由于下载的时候它没有进度，所以请一定要弄个稳定且高速的节点）：https://cobalt.tools/

如果视频无法直接下载视频，可以拆分成视频画面+视频音频下载

视频画面下载（2025年2月3日检查过了，不好用，建议别用）：https://savefrom.com.co/en211th/

视频音频下载：https://loader.to/

字幕下载：https://downsub.com

**三、字幕生成**

有时候某些视频没有字幕，就需要考虑自己生成字幕。

两种方法：云转录、本地转录

云转录可以使用网上的文本转语音功能，有免费最好，但大部分是要付费的。

本地转录可能会有错误，但是有较好的时间轴参考价值。

这里推荐使用开源卡卡字幕助手https://github.com/WEIFENG2333/VideoCaptioner

_翻译完之后，打开输出文件夹，SRT字幕文件在里面_

如果生成的字幕能带上翻译是最好的。

**四、剪辑**

前面要加片头，社区片头文件放[这里](https://github.com/letri1412/RTEDMIntros)了。

然后是视频开头的文本（宋体，左上角，左对齐，小字，黄色）：

```
RELECTECH电子音乐社区翻译组

翻译:

审校：博洛Tonistan

原作者：

```

“翻译：”后面填上你自己的网名，“原作者：”后面填视频平台，加“@”符号，加作者的名字

社区片头和翻译的视频之间最好加个转场（Adobe Premiere快捷键shift+d）

在视频中遇到了不符合法律法规的内容要去掉，广告和推广内容

**五、字幕**

仅需保留中文字幕。

双语字幕随意，但是必须中文在上，另一语言在下。

字幕轨道字体（只要是免费商用都可以）：鸿蒙字体 Medium、思源黑体CN Medium、阿里巴巴普惠体SemiBold

字幕轨道中不可出现[music][音乐]这些字幕

关于贴字翻译，如果在翻译的视频内出现了博主自己的文本，自行斟酌是否要贴字翻译。如果要，那一定要使用风格相似、字号相近、粗细相近的字体，并且有动画一定要尽可能还原，如故障效果和渐入渐出，需要挨着原字幕。

关于嵌字，嵌字是贴字翻译的进化版，直接覆盖原视频文本翻译，虽然效果很好但是需要高技术力，还是自行斟酌。

**六、翻译**

比较耗时间的步骤，需要检查翻译文本的正误，校准时间轴。

翻译文本时要确保语句通顺，可以适当加入梗相关的文本，以及其它更接地气的内容。

专业性的词语无法翻译时，可以使用英文，如果可以，最好在其它位置添加解释文本，但不能阻碍主字幕轨道的阅读（不能遮挡，不能太大）

（2025年4月5日）遇到长难句时可以试试DeepSeek，这里推荐一个万能句式（冒号里面的东西自己填）：

```
怎么翻译（已知语境：）：
```

```
//举个例子
怎么地道地翻译（已知语境：讲解混音的博主觉得音乐制作环节，硬件无需重视）：I am in tons of trouble dealing with those nonsense stuff.
```

**七、审校**

既要检查字幕文本是否合适，又要检查字幕时间轴是否与音频对其，及时查漏补缺。

**八、导出**

视频画幅帧率与翻译的视频相同即可，容器必须是mp4、mkv，目标比特率为2Mbps，大幅度闪动变换的可以适当调高，或者调成可变比特率

音频参数，采样率44100Hz，，如果纯口播，推荐比特率192kbps；如果有音乐演示，推荐拉满，即320kbps

（2025年5月27日）如果有能力把音频做成杜比™全景声混音，那肯定再好不过了，交付给博洛Tonsitan时务必告知要勾选杜比全景声（/杜比音效）
